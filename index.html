01 Selected work

Cladior

Founder and sole engineer · 2026

Payments platform giving third party apps metered billing, shared sign in, saved preferences, a community forum and an app store.

  • Built the metering proxy on Cloudflare Workers: per-kilobyte accounting, wallet debits inside a single transaction, idempotency on retries, SSRF protection on every redirect hop, and fail closed billing, so a charge that errors never delivers a response.
  • Designed the auth layer: site scoped session tokens with expiry, an OAuth style consent flow with strict origin validation, and a browser session gate that meters an ordinary page load without an API client.
  • Wrote the Postgres layer directly, including money in numeric with explicit rounding, row locked balance updates, and a referral ledger.

03 How I work

I develop with Claude Code daily and I am fluent in it: scoping work an agent can execute, driving multi step changes across a codebase, and putting verification around the output rather than trusting it.

In practice that means typecheck gates in CI, tests that fail when a guard stops guarding, and browser driven checks proving a page serves rather than merely builds. Catching what an agent gets quietly wrong is what lets me carry a platform this size alone.
